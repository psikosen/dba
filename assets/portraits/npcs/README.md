## Required Portraits

For each NPC, create portraits with these emotions:
- neutral.png
- happy.png
- sad.png
- worried.png
- sick.png (for affected villagers)
- waking.png (for recovering villagers)

Example filenames:
- chike_neutral.png
- nala_worried.png
- kamari_happy.png
