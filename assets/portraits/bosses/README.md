# Boss Characters

## Boss List (Traditional African Names)

### Spirit World Bosses
1. **Anansi** (Akan, Ghana) - "Spider" - Trickster Spirit (Forest Spirit World)
2. **Mami Wata** (Pan-African) - "Mother Water" - Water Spirit (Chaos Spirit World)
3. **Jengu** (Cameroon) - "Water spirit" - Corruption Spirit (Corrupt Spirit World)
4. **Oya** (Yoruba, Nigeria) - "She Tore" - Storm/Wind Spirit (Harmony Spirit World)
5. **Eshu** (Yoruba, Nigeria) - "Trickster" - Crossroads Spirit (Decay Spirit World)

### Ancient Guardians
6. **Chuma** (Swahili, East Africa) - "Wealth/Iron" - The Iron Sentinel
7. **Nkrumah** (Akan, Ghana) - "Ninth born" - The Ancient Protector
8. **Sundiata** (Mandinka, Mali) - "Lion Prince" - The Warrior King Spirit

### Final Boss
9. **Shango** (Yoruba, Nigeria) - "Thunder" - God of Thunder and Lightning

## Required Portraits

For each boss, create portraits with these emotions:
- neutral.png
- angry.png
- laughing.png
- threatening.png
- defeated.png
- enraged.png

Example filenames:
- anansi_neutral.png
- mami_wata_angry.png
- shango_enraged.png
