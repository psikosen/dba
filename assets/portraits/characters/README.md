# Main Characters

## Character List (Traditional African Names)

### Player Character
- **Kwame** (Akan, Ghana) - "Born on Saturday" - The Shaman protagonist

### Brothers (The Sick Ones)
1. **Kofi** (Akan, Ghana) - "Born on Friday"
2. **Kwesi** (Akan, Ghana) - "Born on Sunday"
3. **Kwadwo** (Akan, Ghana) - "Born on Monday"
4. **Yaw** (Akan, Ghana) - "Born on Thursday"

### Companion Characters
- **Amara** (Igbo, Nigeria) - "Grace"
- **Zuri** (Swahili, East Africa) - "Beautiful"
- **Jabari** (Swahili, East Africa) - "Brave one"

## Required Portraits

For each character, create portraits with these emotions:
- neutral.png
- happy.png
- sad.png
- angry.png
- surprised.png
- determined.png
- sick.png (for brothers)
- waking.png (for brothers)

Example filenames:
- kwame_neutral.png
- kofi_sick.png
- amara_happy.png
